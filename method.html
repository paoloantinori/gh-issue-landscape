How the Issue Landscape Works

From raw GitHub issues to an interactive semantic map — a six-stage pipeline combining NLP embeddings, manifold learning, and density-based clustering.

Pipeline

1

Data Collection

Open issues are fetched from the GitHub API via the gh CLI. Each issue's title and body are concatenated into a single document for embedding.

2

Text Embedding

Each document is converted into a 384-dimensional vector using all-MiniLM-L6-v2, a sentence-transformer model trained on over 1 billion sentence pairs. These vectors encode semantic meaning: issues about similar topics land near each other in vector space. Alternative backends (OpenAI, local API servers) are also supported.

3

Dimensionality Reduction — UMAP

Uniform Manifold Approximation and Projection reduces the 384-dim embeddings down to 2D (or 3D) coordinates for visualization. UMAP preserves both local neighborhoods and global structure better than alternatives like t-SNE or PCA. Configuration: n_neighbors=15, min_dist=0.1, metric=cosine.

4

Clustering — HDBSCAN

Hierarchical Density-Based Spatial Clustering of Applications with Noise discovers topic clusters without requiring a pre-defined number of topics. It identifies groups of varying density and shape, and naturally marks isolated points as outliers ("Uncategorized"). Configuration: min_cluster_size=5, min_samples=3.

5

Topic Labeling — c-TF-IDF

Class-based Term Frequency–Inverse Document Frequency extracts the most distinctive keywords for each cluster. Terms that are frequent within a topic but rare across others are ranked highest. The top 3 keywords (after stopword filtering) become the topic label, e.g. "Schema / Type / Compatibility".

6

Visualization

The final output is rendered in three complementary views: the 2D Semantic Map (DataMapPlot with deck.gl) for spatial exploration, the 3D Explorer (Three.js) for immersive navigation, and the Timeline (Plotly) showing topic evolution over time.

Orchestration — BERTopic

Steps 3–5 are orchestrated by BERTopic, a modular topic modeling framework that integrates UMAP, HDBSCAN, and c-TF-IDF into a unified pipeline. Pre-computed embeddings from step 2 are passed in, so the embedding model is independent of the topic modeling process.
